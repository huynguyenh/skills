# User Preferences

## Local Code Path
- All repos are stored locally under `/Users/hnh/ws/code/github.com/88labs`
- Always check local repos first before cloning or looking elsewhere

## Git Commits
- **NO co-author lines in commits.** Never add `Co-Authored-By` or any co-author trailer to commit messages.
- **NO Claude/AI attribution anywhere.** Never add "Co-Authored-By: Claude", "Generated with Claude Code", "Generated by Claude", or any similar trail in commits, PR descriptions, PR bodies, code comments, or any other output.

## Branch Creation
- **Always ask for a Jira ticket number** before creating a branch for a feature/fix
- Branch format: `{type}/{TICKET-NUMBER}-short-description` (see [repo-and-pr-conventions.md](repo-and-pr-conventions.md))

## Plans
- **Always ask for a Jira ticket number** before creating a plan
- Store plans at: `~/.claude/plans/{JIRA-TICKET-NUMBER}/{YYYY-MM-DD-short-description}.md`
- Example: `~/.claude/plans/APKNOWLEDG-600/2026-02-26-migration-patch.md`
- **When working on a branch**, check if the ticket number in the branch name has existing plans under `~/.claude/plans/{TICKET}/` — if so, read them first and reflect on previous context before proceeding
- Multiple plans can exist per ticket (different dates/approaches)
